# MOB-003: Mobile: camada SQLite nativa (expo-sqlite) + download/cache dos .sqlite

## Contexto

O web consulta `carris.sqlite`, `metro-porto.sqlite` e `public-services.sqlite` via sql.js (WASM) — ver `apps/web/src/lib/staticDb.ts`, `metroPortoDb.ts`, `publicServicesDb.ts`. Os ficheiros são gerados no CI (`pnpm --filter web build:db`) e publicados no GitHub Pages (refresh diário).

## Objetivo

- Camada equivalente com `expo-sqlite` (mesma API `queryAll`/`getStaticDbMeta`).
- Download dos `.sqlite` publicados no GitHub Pages para o armazenamento da app, com cache e atualização baseada na tabela `meta` (`generated_at`).
- Funcionamento offline após o primeiro download; fallback/erro claro sem rede.
