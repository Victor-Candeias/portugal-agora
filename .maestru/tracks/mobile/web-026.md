# WEB-026: Proteção Civil: comunicados da ANPC via API Aberta (/anpc/warnings)

## Contexto

`GET /v1/anpc/warnings` devolve os comunicados da ANPC/ANEPC (via fogos.pt), paginados (`meta` + `data`, com `id` e `text`). Exemplo: proibição de queimas e queimadas. No teste de 2026-10-09 havia 39 comunicados. A app só usa `/anpc/incidents` e `/anpc/summary` (`packages/core/src/api/anpc.ts`).

## Objetivo

- Adicionar `getWarnings()` ao cliente ANPC no core.
- Mostrar os comunicados mais recentes no ecrã Proteção Civil (web `ProtecaoCivil.tsx`, mobile `protecao-civil.tsx`).
- Avaliar também `/anpc/incidents/active`, que já devolve só as ocorrências ativas e evita filtrar no cliente.

## Notas

- `/anpc/risk` veio vazio (`count: 0`) no teste. Manter o RCM do IPMA para o risco de incêndio.
