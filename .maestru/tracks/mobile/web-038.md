# WEB-038: Código Postal: trocar geoapi.pt por moradas.dev (resolver HTTP 429)

## Contexto

A pesquisa de códigos postais (web e mobile) devolve **HTTP 429**. Sem API key, o geoapi.pt (`https://geoapi.pt/cp/{cp}?json=1`) só permite **5 pedidos por dia por IP** (`RateLimit-Policy: 5;w=86400`) e a chave é paga.

A **moradas.dev** (`https://moradas.dev`) é gratuita, incluindo uso comercial. Não pede API key nem registo, tem CORS `*` e um limite de cerca de 50 pedidos por 10 s por IP (o `/cp` tem um limite próprio, mais folgado). Os dados são atualizados todas as semanas e a resposta de `/cp` traz `Cache-Control: max-age=86400`. Está em beta e sem garantia de disponibilidade.

## Objetivo

### 1. Trocar a fonte em `packages/core/src/api/codigoPostal.ts`
- Usar `GET https://moradas.dev/cp/{cp7}`.
- Mapear a resposta para o tipo `CpInfo` atual, para que as páginas web e mobile não mudem:

| CpInfo (geoapi) | moradas.dev |
|---|---|
| CP / CP4 / CP3 | `cp7` / `cp4` / `cp3` |
| Distrito / Concelho / Localidade | `distrito` / `concelho` / `localidade` |
| Designação Postal | `localidade` (não há campo próprio) |
| partes[].Artéria / Troço / Porta / Cliente | `arterias[].street` / `troco` / `porta` / `cliente` |
| partes[].Local | — (não existe) |
| centro (coordenadas) | — (**não existe**, ver ponto 2) |

- Tratar o 404 `{"error":"CP7 not found"}` como "código postal não encontrado". O cabeçalho `X-Moradas-Hint` explica o motivo.
- Tratar o 429: ler `Retry-After` e mostrar uma mensagem clara, sem repetir pedidos em ciclo.
- Não guardar `art_id`, porque muda a cada atualização dos dados.

### 2. Manter o "Ver no mapa" (`centro`)
A moradas.dev não devolve coordenadas. Há duas opções:
- **a)** Geocodificar `localidade` + `concelho` com o Open-Meteo geocoding, que a app já usa no Tempo. A precisão é ao nível da localidade.
- **b)** Esconder o botão/mapa quando não houver coordenadas.

Decidir entre a) e b) antes de implementar.

### 3. Ecrãs
- Rever `apps/web/src/pages/CodigoPostal.tsx` e `apps/mobile/app/codigo-postal.tsx` para os campos opcionais (`Local`, `centro`).
- Atualizar a atribuição/fonte mostrada na UI de "geoapi.pt" para "moradas.dev".

## Fora de âmbito (possíveis extras, a criar à parte se for preciso)
- Pesquisa por rua/morada com autocomplete (`GET /suggest?q=`, e `GET /resolve?art=&numero=` para o CP7 exato pelo número de porta).
- Lista de todos os CP7 de um CP4 (`GET /cp/{cp4}`).

## Notas
- Ficheiros: `packages/core/src/api/codigoPostal.ts`, `apps/web/src/hooks/useCodigoPostal.ts`, `apps/mobile/hooks/useCodigoPostal.ts`, `apps/web/src/pages/CodigoPostal.tsx`, `apps/mobile/app/codigo-postal.tsx`.
- Fallback opcional: Zippopotam.us (`api.zippopotam.us/pt/{cp7}`) dá só a localidade, o distrito e coordenadas ao nível da cidade.
- A fonte e a licença dos dados não estão publicadas (provavelmente dados dos CTT). Para uso local, o risco é baixo.
