# MOB-002: Mobile: mover lógica partilhável do web para packages/core

## Contexto

A lógica de acesso a dados das secções que só existem no web vive em hooks de `apps/web/src/hooks` (`useCarris`, `useHospitais`, `useTransportes`, `useMetroPorto`, `usePublicServices`, `useCodigoPostal`, `useANPC`) e depende de `import.meta.env`, proxies Vite/corsproxy e `fetch` a `BASE_URL`. `packages/core` já é agnóstico de plataforma (ex.: transporte plugável em `sigtur.ts`).

## Objetivo

- Extrair clientes/funções puras (fetch, normalização, haversine, tipos `CMLine`/`CMStop`/…) para `packages/core`, sem `import.meta`, `document` ou `window`.
- Configuração injetável (API key, base URLs, transporte) para web e mobile.
- Hooks React Query ficam finos em cada app; o web mantém comportamento atual (sem regressões).
- No nativo, CP (`comboios.live`) e restantes APIs usam `fetch` direto (sem proxy CORS).
