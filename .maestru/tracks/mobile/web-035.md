# WEB-035: Combustível: preços por posto com raio a partir do GPS (/fuel/stations)

## Contexto

`GET /v1/fuel/stations` devolve os preços posto a posto, com filtros (`district`, `lat`, `lng`, `radius`, paginação). O método `getFuelStations()` já existe no `ApiAbertaClient`, mas nenhum ecrã o usa. A página/tab Combustível usa hoje a DGEG diretamente (`useFuelPrices`).

## Objetivo

- Avaliar se a API Aberta pode substituir ou complementar a DGEG para a lista de postos.
- Mostrar os postos mais próximos (raio a partir do GPS do utilizador, com fallback) com preço por combustível e mapa (web e mobile).

## Notas

- Se a DGEG já der o mesmo com igual qualidade, fechar este item como `archived`.
