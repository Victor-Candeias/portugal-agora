# WEB-035: Combustível: preços por posto com raio a partir do GPS (/fuel/stations)

## Contexto

`GET /v1/fuel/stations` devolve os preços posto a posto, com filtros (`district`, `lat`, `lng`, `radius`, paginação). O método `getFuelStations()` já existe no `ApiAbertaClient`, mas nenhum ecrã o usa. A página/tab Combustível usa hoje a DGEG diretamente (`useFuelPrices`).

## Objetivo

- Avaliar se a API Aberta pode substituir ou complementar a DGEG para a lista de postos.
- Mostrar os postos mais próximos (raio a partir do GPS do utilizador, com fallback) com preço por combustível e mapa (web e mobile).

## Notas

- Se a DGEG já der o mesmo com igual qualidade, fechar este item como `archived`.

## Avaliação (2026-10-09) — arquivado

Testei `GET /v1/fuel/stations` com dados reais:

- **Os filtros geográficos não funcionam**: `lat=38.7223&lng=-9.1393&radius=5` (Lisboa) devolve postos de Odemira e de Coimbra, e o `total` (3345) é igual ao do pedido sem filtros. Só o `district` filtra (Lisboa = 409).
- **Só um combustível**: os 3345 registos são todos "Gasolina simples 95", um por posto. Não há gasóleo, GPL, gasolina 98 nem outros.
- **Dados com idades muito diferentes**: o `updated_at` vai de 2026-02-20 a 2026-10-09. Há postos com preços de há vários meses.

A DGEG, que já usamos (`useFuelPrices`), tem todos os combustíveis e preços atuais. O raio a partir do GPS, a ordenação por preço ou distância e o mapa já existem no web e no mobile (MOB-010, WEB-036). A API Aberta não acrescenta nada, por isso o item fica arquivado, como previsto nas Notas. `getFuelStations()` fica no core, para uso futuro se a API melhorar.
