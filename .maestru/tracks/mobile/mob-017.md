# MOB-017: EV (mobile): Tarifas CEME com mais quantidades de kWh e valor personalizado

## Contexto

O simulador de carregamento da tab EV → "Tarifas CEME" (`apps/mobile/app/(tabs)/ev.tsx`) só tinha 10/20/30/50 kWh. Não dava para simular cargas pequenas nem baterias grandes (60–100 kWh). O endpoint da API Aberta `/ev/tariffs/cheapest?kwh=` aceita qualquer valor. O web já tem um campo "Outro" até 200 kWh.

## Implementação

- Presets 5, 10, 20, 30, 40, 50, 60, 75 e 100 kWh (`ChipRow`, desliza na horizontal).
- Campo "Outro" (teclado decimal, aceita vírgula) de 1 a 200 kWh, como no web. O pedido à API é feito 400 ms depois de parar de escrever. Fora do intervalo aparece uma mensagem de erro e mantém-se o último valor válido.
- Linha "A simular X kWh" com o valor efetivamente usado.
- Validado contra a API: 12,5, 75 e 100 kWh devolvem custos por CEME.
