# WEB-039: Deploy Pages: passar VITE_APIABERTA_KEY ao build a partir do secret APIABERTA_KEY

O build do `deploy.yml` corria sem `VITE_APIABERTA_KEY`, pelo que o site no GitHub Pages falhava
nas páginas da API Aberta (ex.: EV) com "Chave da API Aberta em falta".

Implementado: o job `build` declara `environment: github-pages` e o passo `Build` recebe
`VITE_APIABERTA_KEY: ${{ secrets.VITE_APIABERTA_KEY }}` (secret do ambiente `github-pages`).
A chave fica embutida no bundle público do Pages.
