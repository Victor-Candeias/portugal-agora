# WEB-037: Header: botão para voltar ao Início, à direita na linha Portugal-Hoje, quando fora do menu principal

## Contexto

No web, o cabeçalho (`apps/web/src/components/Layout.tsx`, `<header>`) tem uma linha com "🇵🇹 Portugal-Hoje", que não é clicável. Por baixo fica a barra de navegação com todas as secções. Fora do Início (`/`, Dashboard) não há nenhum atalho visível nessa linha para voltar ao menu principal.

## Objetivo

- Quando a rota atual **não** for `/`, mostrar um botão na mesma linha do texto "Portugal-Hoje", **encostado à direita** (ex.: ícone casa + "Início"), que navega para `/`.
- No Início (`/`) o botão não aparece.
- Usar `useLocation()`/`Link` do `react-router-dom`. Layout com `justify-between` (ou `ml-auto` no botão), sem alterar a altura do header (`h-14`).
- Em ecrãs pequenos, mostrar só o ícone, como na barra de navegação (`hidden sm:inline` no texto).

## Notas

- Assumido que "menu principal" = página Início (`/`).
- Mobile (opcional, a confirmar): o texto "🇵🇹 Portugal Hoje" só aparece no header da tab Início (`apps/mobile/app/(tabs)/_layout.tsx`). O equivalente seria um `headerRight` com botão "Início" nas outras tabs e nos ecrãs da Stack (`apps/mobile/app/_layout.tsx`), que hoje só têm "Voltar".
