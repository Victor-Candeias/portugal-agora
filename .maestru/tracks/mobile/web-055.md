# WEB-055: Energia (web e mobile): cliente de dados no core + cache

## Contexto

As apps leem os artefactos publicados pelo pipeline (WEB-053). O refresh visual não cria dados novos: só relê os ficheiros publicados (relatório `Documents/relatorio_energia_portugal.md`, secções 5 e 11).

## Objetivo

- **Core** (`packages/core/src/api/energy.ts`): `createEnergyClient({ baseUrl, fetch })` com `getLatestEnergy`, `getEnergyDaily` e `getEnergyTimeseries(range)`, validação do contrato com `zod` e erros tipados.
- **Web:** URL a partir de `import.meta.env.BASE_URL`; pedidos com `cache: 'no-cache'`; cache em `localStorage` com fallback para a cache expirada; hook `useEnergy`.
- **Mobile:** URL do GitHub Pages (como o `staticDb` do MOB-003); cache em `expo-sqlite/kv-store`; offline com o último dataset e indicação da antiguidade; hook `useEnergy`.

## Notas

- Se as apps lerem o `energy.sqlite`, reutilizar o `staticDb` (sql.js no web, expo-sqlite no mobile). Decidir na spec.
