# WEB-070: Tráfego aéreo: proxy com cache para a adsb.lol (contrato /air-traffic)

## Contexto

Origem: `Documents/implementacao_trafego_aereo_web_mobile.md` (§3, §4, §5.4, §9). A web está no GitHub Pages e não pode chamar a adsb.lol, por falta de CORS. O mobile gastaria a quota de 500 pedidos/dia por IP. É preciso um intermediário que faça poucas chamadas à fonte e sirva muitos clientes. A plataforma é decidida no WEB-068.

## Objetivo

1. Criar o proxy (Cloudflare Worker, serviço Docker local ou o que for decidido no WEB-068) com o contrato §4:
   - `GET /air-traffic/aircraft?region=mainland|azores|madeira`
   - `GET /air-traffic/aircraft/{icao24}`
   - `GET /air-traffic/stats?region=…`
   - `GET /air-traffic/health`
2. Usar a normalização e a deduplicação do core (WEB-069). Consultar os centros de cada região com concorrência limitada e respeitar 4 pedidos/s e 60/min.
3. A cache por região deve ter um TTL compatível com as quotas. Um pedido de um cliente nunca deve gerar uma chamada à fonte se houver um snapshot válido. Os pedidos concorrentes à fonte devem ser agrupados num só.
4. Se a fonte falhar, devolver o último snapshot com `isStale: true` e a idade. Em 429 ou 5xx, aplicar backoff e respeitar `x-ratelimit-reset`.
5. Segurança e operação:
   - CORS restrito à origem do Pages;
   - rate limiting por cliente;
   - HTTPS;
   - logs sem dados sensíveis;
   - `User-Agent` identificável.
6. Documentar o URL base (variável de build para a web e `STATIC_DATA_BASE_URL` ou equivalente para o mobile) e a forma de fazer o deploy no README.

**Fora de âmbito:** a trajetória (`/track`), porque exige persistência, e o MongoDB. Ficam para a fase 2.

## Critérios de aceitação

- Com N clientes em simultâneo, a fonte recebe no máximo uma chamada por centro em cada ciclo de TTL.
- 200, 429, 5xx, timeout e JSON incompleto são tratados. Uma falha da fonte devolve um snapshot com `isStale` e nunca dá erro 500 sem corpo.
- CORS validado a partir do domínio do Pages.
- Antes de implementar, criar uma spec (`implementation-plan-v1`).
