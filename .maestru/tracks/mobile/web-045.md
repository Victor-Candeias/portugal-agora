# WEB-045: Combustível (web e mobile): custo de atestar o depósito (50 L por omissão, editável)

## Contexto

Pedido: na página de combustíveis, mostrar o preço de atestar um depósito de 50 litros, com o valor editável. Pedido para web e mobile.

## Decisões

- Helpers no core (`packages/core/src/utils/fuelTank.ts`): `DEFAULT_FUEL_TANK_LITRES = 50`, `MAX_FUEL_TANK_LITRES = 200`, `parseTankLitres` (aceita vírgula), `fuelTankCost` (arredondado ao cêntimo), `formatEuros` e `formatLitres`.
- O valor é guardado no dispositivo com a chave `portugal-hoje:fuel-tank-litres` (localStorage na web, `expo-sqlite/kv-store` no mobile). Só se guardam valores válidos.
- Um valor inválido (fora de 1–200 L) mostra um erro e esconde os custos.

## Implementação

- Web: `useFuelTankLitres` em `apps/web/src/hooks/useFuel.ts`. Em `apps/web/src/pages/Combustivel.tsx` há um campo "Depósito (L)" nos filtros, "Atestar X L" nos cartões mais barato/média/mais caro e "⛽ X L: €" em cada posto.
- Mobile: `apps/mobile/hooks/useFuelTank.ts`. Em `apps/mobile/app/(tabs)/combustivel.tsx` há uma linha "Depósito" com TextInput decimal, o custo no cartão "mais barato" e o custo em cada posto (`StationItem`).
- README atualizado.

## Validação

- Web: `pnpm build` e oxlint OK. Mobile: `pnpm typecheck` e `pnpm lint` OK.
- Teste Node: 1,749 €/L × 50 L = 87,45 €; "0" e "201" são inválidos; "45,5" dá 45,5 L.
