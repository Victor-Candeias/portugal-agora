# MOB-005: Mobile: ecrãs em falta (Proteção Civil, Hospitais, Transportes, Metro Porto, Serviços Públicos, Código Postal)

## Contexto

`apps/mobile` tem 6 tabs (Início, Combustível, Tempo, EV, Economia, Turismo); o web tem 12 páginas. Proteção Civil só aparece parcialmente no Início.

## Objetivo

Paridade funcional com o web, por ecrã:
- Proteção Civil — ocorrências ANPC + risco de incêndio.
- Hospitais — urgências SNS próximas (GPS, fallback Lisboa).
- Transportes — Carris (linhas/paragens via SQLite, chegadas/veículos em tempo real) + comboios CP.
- Metro do Porto — estações e próximas partidas.
- Serviços Públicos — PSP/GNR perto de mim.
- Código Postal — pesquisa + mapa.

Rever navegação (12 secções não cabem em tabs — usar Início como grelha/stack).
