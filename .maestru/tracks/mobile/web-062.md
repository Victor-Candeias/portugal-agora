# WEB-062: Paridade web/mobile: resumos CEME e Contratos no Início do mobile; NIF/VIES no web publicado

## Contexto

Comparação web × mobile de 2026-10-19: as 18 rotas da web têm ecrã equivalente no mobile, mas há duas diferenças de funcionalidade.

1. **Início do mobile** (`apps/mobile/app/(tabs)/index.tsx`): faltam dois resumos que o `Dashboard` web tem:
   - «CEME mais barato» (web: `useCheapestEvTariffs`, `apps/web/src/hooks/useEv`);
   - Contratos Públicos recentes (web: `useBaseContracts`, `apps/web/src/hooks/useContratos`).
2. **NIF / VIES na web publicada:** o VIES não tem CORS. A web só consulta o nome e a morada em desenvolvimento, através do proxy do Vite (`/api/vies` em `vite.config.ts`). Em produção, `viesClient` é `null` (`apps/web/src/lib/clients.ts:57-59`) e a página mostra só um link para o formulário do VIES. O mobile chama o VIES diretamente.

## Objetivo

- Acrescentar ao Início do mobile os resumos «CEME mais barato» e «Contratos Públicos», com o mesmo conteúdo e a mesma navegação da web (tocar → separador EV/Tarifas CEME e ecrã Contratos). Reutilizar o core e os hooks do mobile que já existem.
- Dar à web publicada (GitHub Pages) a consulta do VIES, ou registar a limitação como definitiva.

## Decisão em aberto (VIES na web)

O GitHub Pages é estático e o VIES não envia cabeçalhos CORS, por isso o browser não o pode chamar diretamente. Opções:
- (a) manter como está (link para o VIES) e documentar a limitação como definitiva;
- (b) proxy CORS próprio (ex.: Cloudflare Worker). Contraria a regra de não usar serviços cloud neste projeto;
- (c) proxy CORS público de terceiros. Envia o NIF a terceiros e não é fiável;
- (d) outra fonte com CORS para o nome e a morada pelo NIF, se existir.

Perguntar ao utilizador antes de implementar a parte do VIES.

## Critérios de aceitação

- O Início do mobile mostra o CEME mais barato e os contratos mais recentes, com estados de carregamento, erro e offline iguais aos outros resumos.
- Na web publicada, o NIF/VIES fica de acordo com a opção escolhida, e o README é atualizado (linhas da secção «Funcionalidades» e «Fontes de dados»).
- Typecheck do mobile, build web e oxlint sem erros.
