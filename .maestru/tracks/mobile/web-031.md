# WEB-031: Contratos Públicos: nova secção com dados BASE (/base/contracts)

## Contexto

A API Aberta expõe os contratos públicos do BASE.gov.pt (2,17 milhões de registos, sincronizados diariamente):

- `GET /v1/base/contracts`: lista paginada dos mais recentes;
- `GET /v1/base/contracts/search?q=`: pesquisa de texto (o `q` é obrigatório);
- `GET /v1/base/contracts/lookup/:id`: detalhe.

Cada registo tem `description`, `contractingEntity`, `awarded`, `value`, `date` e `type`. Nenhuma app tem esta secção.

## Objetivo

- Criar o cliente/tipos no core.
- Nova secção "Contratos Públicos" (web e mobile): lista dos recentes, pesquisa por texto/entidade/NIF e ecrã de detalhe.
- Adicionar a entrada na navegação/Dashboard.
