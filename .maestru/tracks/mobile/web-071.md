# WEB-071: Tráfego aéreo (web): página /trafego-aereo com mapa Leaflet

## Contexto

Origem: `Documents/implementacao_trafego_aereo_web_mobile.md` (§6). A web já tem React 19, Vite, React Query e `leaflet`. Há mapas com Leaflet em `apps/web/src/components/CoverageMap.tsx` e `HotspotsMap.tsx`. A página consome o proxy (WEB-070) com o cliente do core (WEB-069).

## Objetivo

1. Criar a página `apps/web/src/pages/TrafegoAereo.tsx`, a rota `/trafego-aereo`, a entrada no menu e, se fizer sentido, um atalho no Dashboard.
2. Criar o componente `AircraftMap` em Leaflet:
   - ícone vetorial rodado segundo `headingDegrees`;
   - renderização em Canvas ou clustering para centenas de aeronaves;
   - atribuição do OSM ou do fornecedor de tiles já usado no projeto.
3. Hooks em React Query:
   - atualização periódica só com a aba visível;
   - manter o snapshot anterior enquanto carrega;
   - retry controlado.
4. Interface:
   - seletor Continente / Açores / Madeira;
   - contagem de aeronaves e última atualização;
   - pesquisa por ICAO ou callsign;
   - filtros de altitude, velocidade e em terra;
   - painel de detalhe (identificação, altitude, velocidade, rumo, taxa vertical, idade do sinal).
5. Estados: a carregar, erro, fonte indisponível e dados desatualizados (`isStale`). Mostrar «N/D» para os campos ausentes, nunca 0.
6. Avisos e atribuição:
   - fonte adsb.lol e licença;
   - dados possivelmente incompletos ou atrasados;
   - não usar para navegação;
   - o callsign não é um número de voo.
7. Acessibilidade: navegação por teclado, contraste e uma lista textual das aeronaves como alternativa ao mapa.
8. README: acrescentar a fonte à tabela de fontes e a página à lista.

## Critérios de aceitação

- Sem chamadas do browser à adsb.lol: só ao proxy.
- Uma falha do proxy ou da fonte não parte a página e mostra o estado de desatualizado.
- Dados indisponíveis distinguidos de zero.
- Layout utilizável em telemóvel.
- `build:web` sem erros.
- Antes de implementar, criar uma spec (`implementation-plan-v1`).
