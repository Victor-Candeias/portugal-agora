# WEB-028: Web: página Economia (BdP + INE via API Aberta) em vez de ComingSoon

## Contexto

No web, a página Economia (`apps/web/src/pages/Economia.tsx`) é `ComingSoon`. O mobile já tem a tab Economia (MOB-008), com `ApiAbertaClient.getBdpRates()`, `getBdpLendingRates()` e `getIneLatest()` e com rótulos/formatação PT no core.

## Objetivo

- Implementar a página Economia no web, reutilizando o core: taxas BCE/€STR (`/bdp/rates`), taxas de crédito e depósitos (`/bdp/lending-rates`) e indicadores INE/Eurostat (`/ine/latest`).
- Ligar o cartão "Economia" do Dashboard (hoje `ComingSoonCard`).
- Remover ou substituir o hook antigo `useEconomy` do web, se ainda existir.

## Implementação

Ver `web-028-spec`.

- **Web:** a página Economia mostra as taxas de referência (BCE, €STR, TBA), as taxas de crédito e depósitos e os indicadores INE/Eurostat, com um botão Atualizar. O web passa a ter uma instância do `ApiAbertaClient` (`apiClient` em `src/lib/clients.ts`) e hooks em `src/hooks/useEconomia.ts`.
- **Início (web):** o `ComingSoonCard` da Economia foi substituído pelo cartão "Economia · Taxa BCE" (facilidade de depósito + €STR). "Em breve" fica só com o EV.
- **Core:** `BDP_RATE_LABELS`, `formatRate` e `formatBdpPeriod` passaram da tab Economia do mobile para `packages/core/src/utils`. O mobile usa-os agora a partir do core, sem mudança visual.
- **`useEconomy`:** já não existia no web (removido no MOB-008).
