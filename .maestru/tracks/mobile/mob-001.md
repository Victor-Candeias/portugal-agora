# MOB-001: Mobile: setup de build Android (JDK 17, EAS, eas.json, lockfile)

## Contexto

`apps/mobile` (Expo SDK 57 / RN 0.86, package `pt.portugalhoje.app`) nunca teve um build Android configurado. `app.json` tem `extra.eas.projectId: "portugal-hoje"` (inválido — tem de ser o UUID gerado por `eas init`), não existe `eas.json` e existe um `apps/mobile/package-lock.json` que conflitua com o workspace pnpm. O ambiente local tem JDK 25, incompatível com AGP/RN (requer JDK 17).

## Objetivo

- Documentar/configurar JDK 17 + Android SDK para builds locais.
- `eas init` (projectId real) e `eas.json` com perfis `development`, `preview` (APK) e `production` (AAB).
- Remover `apps/mobile/package-lock.json`; garantir `pnpm install` na raiz.
- Validar que o Metro resolve `@portugal-hoje/core` (imports `.js` → `.ts`).
- Build de desenvolvimento a correr num emulador/dispositivo Android.
- Adicionar `tsc --noEmit` e lint ao mobile; atualizar README.

## Bloqueia

MOB-003, MOB-004, MOB-007.

## Progresso (2026-10-08)

Feito (ver `mob-001-spec`): removido `apps/mobile/package-lock.json`; `eas.json` (preview/production); projectId inválido removido do `app.json`; script `typecheck`; README com JDK 17, Android SDK 36, pnpm-only e EAS. JDK 17 validado: `apps/android-auto` `assembleRelease` passa com lint.

**Pendente:**
- `node.exe` sem acesso à rede nesta máquina (`EACCES`) → sem `pnpm install`: correr `typecheck`, validar Metro + `@portugal-hoje/core`, `expo run:android` no emulador, adicionar lint.
- `eas init` (requer conta Expo) para gravar o projectId real.
- Perfil `development` + `expo-dev-client`.
