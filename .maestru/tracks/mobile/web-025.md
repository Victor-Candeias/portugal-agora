# WEB-025: Tempo: avisos meteorológicos do IPMA via API Aberta (/ipma/warnings)

## Contexto

A API Aberta expõe `GET /v1/ipma/warnings`: os avisos meteorológicos ativos do IPMA (nevoeiro, agitação marítima, precipitação, calor…), com `type`, `text`, `startTime`, `endTime` e `region` (código de área, ex.: `BRG`). No teste de 2026-10-09 devolveu 152 avisos. Nenhuma app usa esta rota hoje: o web e o mobile mostram só previsões.

## Objetivo

- Adicionar `getIpmaWarnings()` e os tipos ao `ApiAbertaClient` (`packages/core/src/api/client.ts`).
- Mostrar os avisos ativos na página/tab Tempo (web e mobile), filtrados pela região selecionada, e um cartão resumo no Início.
- Mapear os códigos de região (`BRG`, `LSB`, …) para os nomes de distrito.

## Notas

- Requer a chave da API Aberta (`VITE_APIABERTA_KEY` / `EXPO_PUBLIC_APIABERTA_KEY`).
