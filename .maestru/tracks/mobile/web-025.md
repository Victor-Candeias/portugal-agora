# WEB-025: Tempo: avisos meteorológicos do IPMA via API Aberta (/ipma/warnings)

## Contexto

A API Aberta expõe `GET /v1/ipma/warnings`: os avisos meteorológicos ativos do IPMA (nevoeiro, agitação marítima, precipitação, calor…), com `type`, `text`, `startTime`, `endTime` e `region` (código de área, ex.: `BRG`). No teste de 2026-10-09 devolveu 152 avisos. Nenhuma app usa esta rota hoje: o web e o mobile mostram só previsões.

## Objetivo

- Adicionar `getIpmaWarnings()` e os tipos ao `ApiAbertaClient` (`packages/core/src/api/client.ts`).
- Mostrar os avisos ativos na página/tab Tempo (web e mobile), filtrados pela região selecionada, e um cartão resumo no Início.
- Mapear os códigos de região (`BRG`, `LSB`, …) para os nomes de distrito.

## Notas

- Requer a chave da API Aberta (`VITE_APIABERTA_KEY` / `EXPO_PUBLIC_APIABERTA_KEY`).

## Implementação

Ver `web-025-spec`.

- **Mudança de fonte:** a rota `/ipma/warnings` da API Aberta só tinha 3 regiões (`BRG`, `MCS`, `AOR`; `?region=LSB` devolvia 0) e não trazia o nível do aviso. Os avisos vêm, por isso, do open-data do IPMA (`warnings_www.json`), que tem as 25 áreas e o nível, não precisa de chave e permite CORS. `ApiAbertaClient.getIpmaWarnings()` foi acrescentado, mas as apps ainda não o usam.
- **Core:** `ipmaClient.getWarnings()` devolve só os avisos não verdes e ainda por terminar, por gravidade. Inclui também `IPMA_WARNING_AREAS`, `filterWarningsByDistrict`, `districtFromIpmaCityId`, `maxWarningLevel`, `formatWarningTime` e as cores/rótulos dos níveis.
- **Web:** a página Tempo mostra os avisos do distrito selecionado (do país, com localização). O Início tem um cartão com o número de avisos e o nível máximo.
- **Mobile:** a tab Tempo mostra os avisos do distrito da cidade escolhida. O Início tem o cartão "Avisos IPMA" e uma linha no estado dos dados.
